# Albion Market PWA 2.8.4

Versión web instalable para iPhone, Android y computadores.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `Albion-Market`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/ (root)` y pulsa **Save**.
6. Espera unos minutos y abre la URL que entrega GitHub.

## Instalar en el teléfono

- iPhone: abre la web en Safari → Compartir → Agregar a pantalla de inicio.
- Android: abre la web en Chrome → menú ⋮ → Instalar aplicación.

Los precios dependen de Albion Online Data Project y requieren conexión. El catálogo, la interfaz y las builds quedan guardados para funcionar parcialmente sin conexión después de la primera carga.
